# Автоматические признаки для рекомендаций

Можно ли улучшить сильный градиентный бустинг автоматическим выбором временных агрегатов или заменить их обучаемыми представлениями?

**[Научная статья (PDF)](article.pdf)** — метод, источники, протокол, результаты и ограничения. [Численные результаты](results/) и [рисунки](results/figures/) доступны отдельно.

На KION выбранные окна **2/3/5 дней** дают NDCG@10 **0,165822 против 0,163488** у ручной базы: **+1,43%**, парный 95% интервал разности **[+0,000795; +0,004025]**. Это новые пользователи ранее изученной недели. Исходная смесь шести моделей не показала убедительного выигрыша; замена части агрегатов ALS-представлениями ухудшила качество.

На **Yambda**, в среднем по трём заранее заданным неделям, importance-отбор даёт **0,166251 против 0,165525**: разность **+0,000726**, 95% интервал **[−0,002946; +0,004308]**. Две недели отрицательны, одна положительна; устойчивый выигрыш не подтверждён. Обе системы содержат по три модели.

Добавлены случайный поиск с теми же четырьмя обучениями и замер полного запроса с построением только нужных признаков. Выбор ограничен девятью окнами заданной грамматики; один seed случайного поиска не устанавливает превосходство процедуры. Источники и адаптация рецептов Т-Банка, KION и RecTools — в статье.

## Воспроизведение

Python 3.11; полный расчёт на CPU занимает несколько часов. Для KION рекомендуется 24 GB RAM и 25 GB диска; исходный запуск выполнен на macOS arm64 с 16 GB RAM. Запускать из корня репозитория:

```bash
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/run_experiment.py
.venv/bin/python scripts/random_search_control.py --stage develop
.venv/bin/python scripts/run_yambda.py --stage all
.venv/bin/python scripts/benchmark_serving.py
```

Данные скачиваются автоматически. Истории, срезы и модели остаются в `data/` и `artifacts/`; новые результаты — в `results/rerun.json` (KION), `artifacts/random_control/results.json` и `artifacts/yambda/results.json`. Когорты Yambda закреплены в [протоколе](results/yambda_design.json). При изменении конфигурации задайте новые каталоги кеша и результатов; параметры этапов доступны через `--help`.

Пересборка статьи по опубликованным результатам, без обучения:

```bash
.venv/bin/python scripts/plot_article.py
.venv/bin/python scripts/article.py
```
